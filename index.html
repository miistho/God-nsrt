Guide d'utilisation - Northern Sky Raid Tools (NSRT)

Cliquez sur une des zones entourées ou numérotées pour accéder aux explications détaillées.

Guide NSRT • Section 1

1. Encounter Alerts (Alertes de rencontre)

Cette section permet d'activer ou de désactiver les alertes spécifiques intégrées par l'addon pour chaque boss du raid.

  • Cochez les alertes que vous souhaitez voir apparaître.
  • Type d'affichage (Text, Bar, Icon, Circle) : Permet de choisir la forme visuelle de l'alerte à l'écran (un texte simple, une barre de progression, une icône de sort avec décompte ou un cercle d'alerte).
  • Preview (en haut à droite) : Affiche un aperçu en direct de l'alerte sur votre écran pour vérifier son apparence et sa position.
  • Personnalisez les sons et les comptes à rebours associés.

Guide NSRT • Section 2

2. Note-Display (Affichage des notes)

Réglez ici l'apparence visuelle des notes textuelles affichées à l'écran pendant le combat :

  • Les boutons Unlock (Unlock All Reminders, Unlock Pers Reminder, Unlock Text Note) servent à placer et déplacer librement les fenêtres des notes sur votre écran.
  • Recliquez ensuite sur Unlock pour verrouiller la position des fenêtres une fois qu'elles sont bien placées.
  • Choix de la police d'écriture, de la taille et de l'opacité du fond.
  • Filtrage pour n'afficher que les lignes qui concernent votre personnage.
  • (Show Outside of Raid : permet d'afficher les fenêtres de notes même lorsque vous n'êtes pas dans un groupe de raid, ce qui est très pratique pour tester et régler votre interface tranquillement).
Guide NSRT • Section 3

3. Reminders (Rappels et Timers)

Paramétrez ici le comportement de vos rappels de sorts (CD défensifs, soins, utilitaires) et l'annonce vocale :

  • Case TTS (en haut à gauche, sous Spell Settings) : Active la synthèse vocale (Text-to-Speech) pour que l'addon vous annonce à voix haute le nom du sort à utiliser ou la mécanique à gérer.

Options de la colonne de droite (Manage Reminders) :

  • Preview Alerts : Affiche les cadres des alertes à l'écran pour ajuster leur position et leur taille.
  • Use Shared Reminders : Active les rappels partagés envoyés par le Raid Leader.
  • Use Personal Reminders : Active vos propres rappels personnels.
  • Share on Ready Check : Partage automatiquement la note chargée au raid lors de l'appel (Ready Check).
  • Clear Note on Boss-Kill : Efface automatiquement la note de rappel une fois le boss vaincu. decocher si vous voulez les garder
  • Only Receive Guild Reminders : N'accepte les notes partagées que si elles proviennent d'un membre de votre guilde.
  • Overwrite Shared Notes on Import : Remplace les notes partagées existantes lors d'un nouvel import.
  • Overwrite Personal Notes on Import : Remplace vos notes personnelles existantes lors d'un nouvel import.
  • Automatically Enable New Alerts : Active automatiquement les nouvelles alertes ajoutées lors d'une mise à jour de l'addon.

Attention : il faut recliquer sur le bouton Test Active Reminder pour arrêter le fonctionnement du déroulé de cette fonctionnalité.

Test Active Reminder : Ce bouton permet de lancer une simulation complète en temps réel de vos rappels actifs (comme si un combat de boss venait de démarrer) afin de vérifier l'affichage visuel, les timers et la synthèse vocale hors combat.

Guide NSRT • Notes Partagées

Shared Notes (Notes partagées par le Raid Leader)

Cet onglet contient les assignations globales envoyées à tout le groupe de raid :

  • Réservé principalement aux Raid Leaders et officiers.
  • Utilisez Import pour coller la note WoW Utils, puis Load & Send pour la diffuser au raid.
Guide NSRT • Notes Personnelles

Personal Notes (Vos rappels personnels)

Gérez ici vos propres rappels sans affecter le reste du raid :

  • Cliquez sur Import, collez votre note personnelle puis cliquez sur Load.
  • Assurez-vous que la note est bien chargée avant l'appel (Ready Check).
Guide NSRT • Timeline

Timeline (Chronologie du combat)

L'icône d'horloge ouvre la vue chronologique des capacités du boss et de vos sorts assignés :

  • Faites un clic droit sur la ligne de temps pour ajouter un sort, puis faites-le glisser avec la souris pour le déplacer au moment voulu.
  • Permet de visualiser l'enchaînement des mécaniques du combat.
  • Utile pour vérifier que vos timers sont bien synchronisés avec les phases du boss.
Guide NSRT • Positionnement

Positionnement des alertes et icônes

L'icône d'ancre permet de déverrouiller les éléments à l'écran pour les placer où vous le souhaitez :

  • Déplacez les barres de rappels personnels, les alertes partagées et le cadre de note.
  • Cliquez sur exit preview.
